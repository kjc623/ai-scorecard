Privacy

Private by design

✓

Prompt text stays on the device by default

✓

Only set roles can open a prompt, and every look is audited

✓

No leaderboards of people in the console

✓

A device that stops reporting says so

Default collection sends no prompt text from the device: who (as a pseudonymous reference), the tool, the time, the size, attachment names and the sensitive-data labels. A customer can opt in to full capture, which stores prompts encrypted and makes them searchable. The enterprise connectors, where used, read prompt text from the provider to check it. The console has no leaderboard of people.
