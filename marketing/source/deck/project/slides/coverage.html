Beta

Their admin records, for devices without the agent

In the browser, a rule acts on the tool itself: the extension decides before the prompt is checked for sensitive data, which happens on the device right after. Claude Code, Codex CLI and Cursor check each prompt before it is sent, so there a rule can also act on sensitive data. Microsoft Copilot and Microsoft 365 Copilot send prompts over a connection the extension reads but cannot hold, so they are recorded, not blocked. The enterprise connectors are in beta.
